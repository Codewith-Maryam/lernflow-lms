# lernflow-lms
A Learning Management System (LMS) developed for IT students to access lecture notes, PDF materials, and educational videos using React.js, Laravel, and MySQL.

## 🎯 Project Objectives
- Provide a centralized platform for IT learning resources
- Improve accessibility to educational materials
- Help students learn through organized digital content
